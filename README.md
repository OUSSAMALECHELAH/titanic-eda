🚢 Project Title: Titanic Data Analysis (EDA)
Project Overview
This project explores the famous Titanic dataset to uncover the factors that influenced a passenger's chances of survival. Instead of just relying on historical stories, this project uses data science and statistical analysis to find patterns and hidden stories within the passenger manifest.

Core Objectives
Data Exploration: Understand the structure of the dataset, handle missing data, and clean the passenger profiles.

Feature Analysis: Investigate how different factors—such as Gender (Sex), Socio-economic status (Pclass), Age, and Family size—affected survival rates.

Data Visualization: Use Python libraries (Matplotlib and Seaborn) to create clear, impactful charts that tell the story of that tragic night.

Key Questions Answered
Did the "women and children first" policy actually reflect in the data?

Did buying a first-class ticket guarantee a higher chance of survival?

Did traveling alone or with family make a difference in surviving the disaster?

Tools Used
Python (Core language)

Pandas (Data manipulation and cleaning)

Matplotlib & Seaborn (Data visualization)
